
# Student Task Manager

A Python project that helps students organize their academic tasks.

## Features
- Add tasks
- View all tasks
- Set task priorities
- Mark tasks as completed
- Delete tasks
- Save tasks using JSON file handling

## Technologies Used
- Python 3
- JSON
- File Handling
- Exception Handling

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python task_manager.py`.

## Concepts Practiced
Functions, lists, dictionaries, loops, conditional statements,
file handling, and exception handling.
